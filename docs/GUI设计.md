# 密钥工作台（第二版视觉）

产品是日常查找、复制、分类密钥的工具，优先快速扫描与低频打断。第一版只有灰白和单一青色，字号 10–12 px，所有条目共用同一图标，信息像后台表格；第二版保留结构与安全边界，重做视觉层级、辨识度与深色模式。

## 设计 token

颜色集中在 `apps/gui/lib/ui/theme.dart` 的 `KagiPalette`，组件通过 `context.kp` 取色，不写死颜色。外观跟随系统（`ThemeMode.system`）。

| token | 浅色 | 深色 | 用途 |
| --- | --- | --- | --- |
| canvas | `#FFFFFF` | `#17171B` | 列表区 |
| sidebar | `#F4F4F7` | `#1E1E23` | 侧栏 |
| panel / card | `#F8F8FA` / `#FFFFFF` | `#1B1B20` / `#25252B` | 详情栏与分组卡片 |
| ink / muted / faint | `#1B1B21` / `#64646F` / `#9C9CA8` | `#F1F1F5` / `#A3A3AF` / `#71717C` | 主文字 / 次文字 / 弱提示 |
| accent | `#4352D4` | `#8D99FF` | 靛蓝操作色；选择态用 `selection` 浅底 |
| danger / success | `#C23B3B` / `#1F8458` | `#FF7B72` / `#5BC892` | 归档、过期提醒 / 可用状态 |

- 字体：不指定字体族，使用平台系统字体（macOS 为 SF 与苹方）；引用与验证码用 `SF Mono`，回退 Menlo。主题组件字样显式带平台字体族，避免回退。
- 字号：桌面正文 13，次要 11.5–12，列表标题 13.5 半粗，分区标题 21 粗体，详情标题 19；手机正文 15，分区标题 26。
- 圆角：输入与按钮 8，列表选择 9，分组卡片 12，对话框 14。选择态是圆角浅底，不再用左侧窄色条。

## 布局

```text
桌面（≥ 980）
┌──────────────┬──────────────────────────────────────┬──────────────────────┐
│ ▣ kagi  演示⌄ │ 所有条目 12        [搜索 ⌘F] ⟳ [+新建] │ 条目详情           ✕ │
│ ▤ 所有条目 12 │ [全部|密钥|TOTP|Passkey]      名称 A–Z │ (G) Google           │
│ ▤ 已归档    0 │ (C) Cloudflare  #基础设施 ●工作室 密钥 │     google/auth… ⧉   │
│ Space       + │ (G) Google ⏱    #验证器   ●个人  TOTP  │ ┌ 一次性验证码 ────┐ │
│ ● 个人      3 │ …                                      │ │ 246810       ◔ 6 │ │
│ #API #代码 …  │                                        │ └────── [生成验证码]┘│
│ ⟳ 同步与冲突  │                                        │ ┌ Space / 类型 / … ┐ │
│ 🔒 锁定  ⇧⌘L  │ ● 离线可用         演示数据，不读取真实 │ 备注、编辑、归档     │
└──────────────┴──────────────────────────────────────┴──────────────────────┘
手机
顶栏（品牌、库切换、同步、锁定）→ 大标题 → 搜索 → 类型分段 → 66 px 条目行 → 单独详情页
```

- 侧栏 232 px；详情栏 360 px（窗口窄于 1200 时 320 px）；列表行 56 px，随系统字号放大。
- 列表行：首字母头像（按名称取精选色相，TOTP / Passkey 带角标）、名称 + 等宽引用、最多两个标签、Space 色点、类型徽标。列宽不足时依次隐藏标签与 Space，筛选栏可横向滚动，排序与新建按钮收成图标。
- Space 按顺序取色，侧栏与列表色点一致；标签在侧栏以可点击胶囊展示。
- 类型筛选改为带数量的分段控件，比下拉菜单少一次点击。
- 详情：头像、名称、可复制的引用（引用不是秘密）、类型与 Space 胶囊；值卡片显示遮罩、验证方式和主操作；TOTP 显示倒计时圆环，最后 5 秒变红；管理信息用分组卡片。
- 锁定 / 未配置 / 出错页：居中应用标志与状态角标、浅色径向背景、全宽主按钮。
- 手机：主要操作与导航点击区域至少 44 px；详情页短的淡入 + 轻微位移，系统减少动态效果时为零时长。

## 不变的部分

认证、fake 模式、原生通道、剪贴板与 TOTP 清除规则沿用既有实现，界面不缓存秘密。快捷键：⌘/Ctrl+F 搜索、⌘/Ctrl+N 添加、⇧⌘/Ctrl+L 锁定。

## 视觉检查

`scripts/gui.sh preview` 运行 `apps/gui/tool/capture_preview_test.dart`，用演示库在浅色、深色下渲染桌面（1280、980）与手机（390）的主要界面，PNG 写入 `apps/gui/.preview`（可用 `KAGI_SHOTS` 改目录）。字体按 macOS 或 Linux 的候选路径加载，找不到时 Flutter 测试字体会显示方块，不代表真机效果。
