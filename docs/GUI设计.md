# 紧凑密钥工作台

依据 Anthropic 官方 frontend-design 技能重新审视首版布局。产品是日常查找、复制、分类密钥的工具，优先快速扫描与低频打断，不采用介绍页式的大标题、巨型图标或重复安全文案。

## 设计 token

- 画布 `#FFFFFF`，侧栏 `#F2F4F5`，主文字 `#1F2933`，次文字 `#5F6C76`，边界 `#DDE2E5`，操作强调 `#1E6470`。
- 系统无衬线负责中文、名称、表头和操作；等宽字体仅用于需要逐字核对的引用与验证码。标题 16–18，桌面正文 12–13，手机正文 14；不使用全大写装饰标签。
- 桌面：172 px 侧栏、弹性条目表、300 px 检查器；工具栏 44–48、行高 42。空白用于分组，不把每组内容包成卡片。
- 手机：独立列表与详情页面，行高 58，主要操作与导航点击区域至少 44；不能靠把桌面表格缩成小字来适配。
- 小圆角仅用于输入和按钮（5–7），不做统一大圆角卡片；选择态用深青文字、浅底与窄色条表示。

## 对设计计划的复核

曾考虑保持三块大面板并整体缩小，但这仍会重复名称、引用和状态，且让密钥管理像通用卡片仪表盘。改为表格承担横向比较，检查器承担单条操作；引用使用等宽字是为了核对机器标识，标签与普通辅助文字仍用系统字体。没有装饰性数据、营销标语、渐变、巨大图标或全大写眉题。

窄桌面自动收起次要表格列，手机改为分层导航；长引用、标签和名称必须可截断/换行，操作必须有键盘焦点。搜索支持 Cmd/Ctrl+F，添加支持 Cmd/Ctrl+N，锁定支持 Cmd/Ctrl+Shift+L。认证、fake 模式与原生接口的安全边界沿用既有实现。

参考：[Anthropic frontend-design](https://github.com/anthropics/skills/blob/main/skills/frontend-design/SKILL.md)。技能应用于 Flutter 的视觉与交互实现，不引入 WebView 或替换现有核心。

截图复核后进一步修正：辅助文字在侧栏上的对比度提升到约 4.89:1；默认窗口缩至 1120×720，仍可同时显示五列表格。手机放大字号时简化品牌字标，让可读内容与 44 px 操作区域优先；演示／本机标记在详情页仍保留。

手机详情只使用短的用户触发过渡；系统启用减少动态效果时，正向与返回过渡均为零时长。
